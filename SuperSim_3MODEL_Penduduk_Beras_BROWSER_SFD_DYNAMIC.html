📌 Cara Kerja

SuperSim membaca struktur masalah, lalu membentuk model contoh pertumbuhan penduduk.
Stock = Jumlah Penduduk
Flow = Pertambahan Penduduk
Auxiliary = Laju Lahir, Laju Mati
Population' = Births − Deaths

🔍 Interpretasi CLD

Penduduk ↑ → Kelahiran ↑ → Penduduk ↑
Penduduk ↑ → Kematian ↑ → Penduduk ↓
Penduduk / Luas Wilayah → Kepadatan
Loop pertumbuhan penduduk bersifat reinforcing karena lebih banyak penduduk menghasilkan lebih banyak kelahiran ketika birth rate konstan.

🧱 SFD — PowerSim Style

Struktur SFD mengikuti pola pada diagram PowerSim: Stock = kotak, Flow = pipa/katup, Auxiliary = lingkaran, Cloud = source/sink, dan information link = garis pengaruh.

🔗 Struktur Delay Material

Migrasi Direncanakan → DELAYMTR-1 → DELAYMTR-2 → DELAYMTR-3 → DELAYMTR → PENDUDUK_AKTUAL

Orde 3 ditampilkan sebagai tiga tahap delay agar struktur model dapat diaudit secara visual.

🔗 Struktur Delay Informasi

PENDUDUK_AKTUAL → DELAYINF-1 → DELAYINF-2 → DELAYINF → KELAHIRAN / KEMATIAN

Orde 2 ditampilkan sebagai dua tahap delay informasi.

⚙️ Parameter Simulasi + Function Engine

🧩 Fungsi System Dynamics

Baseline tugas: Penduduk awal 500.000; kelahiran 1,8%; kematian 0,7%; migrasi 14.000 jiwa/tahun; DELAYMTR orde 3 dengan initial 0 dan tau 2 tahun; DELAYINF orde 2 dengan initial 500.000 dan tau 3 tahun. IF dan STEP tetap tersedia sebagai fungsi tambahan.
IF(Population ≥ Threshold, BirthRate×TrueFactor, BirthRate×FalseFactor)
STEP(t) = 0 jika t < StartTime; STEP(t) = StepValue jika t ≥ StartTime
DELAY1(x, τ) = delayed + (x − delayed) × dt / τ
